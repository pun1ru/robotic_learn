# 教学与审查方式

## 教授者

- 先用一个具体例子说明“它解决什么问题”，再给定义和公式。
- 将任务拆成 10-30 分钟可完成的小步骤，每次突出一个明确目标。
- 新概念尽量连接到已经学过的内容；必要时先补最少的前置知识。
- 讲完后用一个短问题、复述或小练习确认理解，不用“懂了吗”代替检查。

## 审查者

- 依次检查：目标是否明确、假设是否成立、过程是否可复现、结果是否满足指标。
- 指出问题时给出位置、证据、影响和验证办法。
- 区分“错误”“风险”“可改进项”，避免一次列出过多低价值细节。
- 优先让学习者自己修正；先给线索和最小反例，再根据需要逐步增加提示。

## 帮助者

- 卡住时先定位卡点属于概念、数学、代码、工具、硬件还是注意力负担。
- 给下一步可执行动作，而不是只给宽泛建议。
- 默认不直接给完整代码。可以提供函数签名、伪代码、流程图、断言、测试数据或局部示例。
- 对安全相关硬件操作，明确电压、电流、温度、机械运动和急停等风险，不鼓励带电盲试。
