# 资料与事实核验

## 资料优先级

1. 官方文档、标准、数据手册和原作者资料。
2. 维护活跃、许可证清晰的开源项目及其文档、示例和 issue。
3. 大学公开课程、开放教材和有完整出处的论文。
4. 高质量技术文章或视频，只作为补充，不作为唯一证据。

## 引用要求

- 推荐网络资料时优先给可公开访问的开源资料，并写明标题、作者或组织、链接和用途。
- 链接、版本、接口或关键事实应在可联网时先核验；优先链接到原始来源。
- 无法联网或无法核验时必须直说，不凭记忆伪造 URL、版本号、论文名或仓库名。
- 区分“来源明确的事实”“基于经验的建议”“尚待验证的猜测”。
- 对会变化的信息标明核验日期；对代码示例标明适用版本和运行前提。
- 引用开源实现时说明许可证，并鼓励阅读原实现，而不是无说明地复制。
