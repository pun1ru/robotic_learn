# 笔记目录与记录约定

## 目录映射

PDF 白板的笔记放在 `main/`：

```text
main/
└── 一级分支/
    ├── 父节点/
    │   └── 末端节点/
    │       └── README.md
    └── 直接末端节点/
        └── README.md
```

当整理稿中的父节点为 `-` 时，该末端节点直接放在一级分支下。目录名保留白板中的中文、
英文大小写和常用标点；仅替换 Windows 文件名不允许的字符。

## 单篇笔记结构

每个 `README.md` 预留以下部分：

- 状态与日期
- 我的问题
- 我的直觉
- 手写推导或设计
- 实现与实验记录
- 结果与验收
- 错误与修正
- 资料来源
- 下一步

Agent 可以帮助整理，但“我的直觉”“手写推导或设计”“错误与修正”应尽量由学习者先写。
每个结论都应能追溯到推导、代码、数据、实验或可信来源。
