# 笔记目录与记录约定

## 目录映射

PDF 白板的笔记放在 `main/`：

```text
main/
└── 一级分支/
    ├── 父节点/
    │   └── 末端节点/
    │       └── README.md
    └── 直接末端节点/
        └── README.md
```

当整理稿中的父节点为 `-` 时，该末端节点直接放在一级分支下。目录名保留白板中的中文、
英文大小写和常用标点；仅替换 Windows 文件名不允许的字符。

## 单篇笔记结构

每个 `README.md` 只保留以下 6 个部分，避免冗余：

- 状态：只写当前状态，例如“未开始”“进行中”“已完成”。
- 日期：开始日期和最近更新。
- 理论知识：概念、直觉、公式与推导。
- 实践：条件与参数、过程、结果与验收、错误与修正、下一步；需要时作为 `###` 子标题写在
  这一节内。
- 问题：自己的疑问。
- 参考资料：来源清单，没有来源时留空。

不设“目标”部分：白板目标与验收统一放在 `memory/whiteboard_leaf_goals.md`，笔记内不重复。

Agent 可以帮助整理，但“理论知识”中的直觉与推导、“实践”中的错误与修正应尽量由学习者
先写。每个结论都应能追溯到推导、代码、数据、实验或可信来源。

## 公式显示约定

- 默认使用 Markdown 行内代码或代码块表达公式，例如 `G(s) = 10 / [s(1 + 0.2s)(1 + 0.05s)]`。
- 不默认使用 `\[...\]`、`$$...$$` 或依赖 LaTeX 渲染的公式块；只有确认目标阅读器支持时才使用。
- 公式中的乘法、分式和括号优先采用 ASCII 写法，确保在终端、编辑器和网页中都能正常阅读。
