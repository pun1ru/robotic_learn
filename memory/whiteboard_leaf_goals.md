# 白板末端节点实践目标

来源：`whiteboard_exported_image.pdf`  
范围：9 个一级分支，共 171 个末端节点。

## 使用原则

- 每个目标必须留下可复查产物：代码、模型、原理图、波形、数据集、测试报告或推导文档。
- 优先级依次为：实机实验 > 硬件在环/仿真 > 可复现实验代码 > 理论推导。
- 验收时必须保存输入条件、参数、原始数据和结论；不能只保存最终截图。
- 表中的数值是默认验收线。设备条件不匹配时可调整阈值，但不得删除对照实验和量化指标。
- 难度系数采用 `1.0-5.0`：`1.x` 入门复现、`2.x` 单模块实践、`3.x` 综合实验、`4.x` 复杂系统、`5.0` 研究型任务。
- 系数综合理论深度、设备门槛、实现规模和验收成本；它表示完成难度，不表示学习价值。

## 建议执行方式

不要按白板从上到下机械学习。更有效的做法是围绕一个真实项目把多项串起来，例如“电机速度控制实验”可同时覆盖传递函数、系统辨识、PID、采样、编码器、CAN/FDCAN、日志、FFT 和 MATLAB/Python。每完成一个项目，再回到本清单勾选有证据支撑的节点。

建议每项保存以下最小证据：

1. `README`：问题、设备/模型、步骤和结论。
2. 可运行代码或可编辑模型。
3. 原始数据与参数文件。
4. 一张对照图或波形，不只截最终成功画面。
5. 验收指标表：目标值、实测值、是否通过、失败原因和下一步。
