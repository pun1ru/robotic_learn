## 理论知识

- 万象锁为啥啊:旋转变换不满足交换率,先绕x转10再绕y转90,再绕x转10,采用旋转矩阵描述X(10)Y(90)X(10)和X(20)Y(90)并不一样,采用欧拉角描述,欧拉角是一个状态的变换,规定了旋转顺序,比如说xyz,所以展示动画化的先绕x转10再绕y转90,再绕x转10实际只有先绕x20然后绕y90,欧拉角所描述的姿态都是由初始姿态经过变换得到的,欧拉角可以描述一个物体在三维空间所有的姿态但是描述方式并不唯一,欧拉角描述的是过程而非结果,变换到一个姿态有多种方式,但是实际旋转矩阵都是唯一的。
  经典例子：在 ZYX 顺序下，当第二次旋转（绕Y轴的Pitch）为 pm90 度时，第一次旋转的Z轴和第三次旋转的X轴就会重合（或者说指向相反方向）。
  后果：此时，你再去调整Roll和Yaw，会发现它们的效果是相同的，都是让物体绕着同一个轴旋转。你就无法做出某些独立的姿态调整了，这是因为第一次旋转轴和第三次旋转轴实际上看来是相同的，由于欧拉角属于变换，相当于只有一次变换就到达目标姿态,此时调整roll，yaw实际上是在对同一个轴进行旋转,而不是理想中的绕旋转后的roll进行变换，因为这个在第一次就做完了，你理解的第二次变换是假的，所以对于连续旋转的表示十分不友好.
