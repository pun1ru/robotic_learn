# RT1064 核心板扩展排针功能

封装：`U8 / MIMXRT1064xVL_CoreBoard`

所有普通 IO 为 `3.3V` 逻辑，不能直接接 `5V` 信号。

## 电源与控制

- `1, 2, 83`：GND
- `3, 4`：3V3
- `5, 6`：5V 输入
- `7`：OF，特殊电源控制脚
- `8`：WU，唤醒脚
- `9`：CR，内核启动完成输出，用于外设电源 EN

## PWM、电机、SPI、无线

- `10 / D4`：普通 GPIO
- `11 / D3`：PWM
- `12 / D2`：PWM
- `13 / D1`：PWM 或 UART4_RX
- `14 / D0`：PWM 或 UART4_TX
- `15 / D12`：PWM 或 SPI1_SCK
- `16 / D13`：PWM 或 SPI1_CS
- `17 / D14`：PWM 或 SPI1_MOSI
- `18 / D15`：PWM 或 SPI1_MISO
- `19 / D16`：PWM 或 UART8_TX
- `20 / D17`：PWM 或 UART8_RX
- `81 / D27`：GPIO 或 SPI1_CS3
- `84 / D26`：GPIO 或 SPI1_CS2

## 屏幕与串口

- `23 / B0`：SPI3_SCK，屏幕时钟
- `24 / B1`：SPI3_MOSI，屏幕数据
- `25 / B2`：屏幕控制 GPIO
- `26 / B3`：SPI3_CS，屏幕片选
- `27 / B13`：UART1_RX
- `29 / B12`：UART1_TX
- `48 / B10`：GPIO 或 I2C
- `49 / B9`：GPIO 或 I2C，连接板载 LED，慎用
- `61 / C19`：屏幕控制 GPIO
- `64 / C18`：屏幕控制 GPIO

## ADC

- `28 / B15`
- `30 / B14`
- `31 / B17`
- `32 / B16`
- `33 / B19`
- `34 / B18`
- `35 / B21`
- `37 / B23`

## 编码器

- 编码器 1：`34 / B18`、`33 / B19`
- 编码器 2：`80 / C2`、`58 / C24`
- 编码器 3：`77 / C3`、`55 / C25`
- 编码器 4：`82 / C0`、`79 / C1`

## IMU SPI

- `57 / C23`：SCK
- `60 / C22`：MOSI
- `59 / C21`：MISO
- `62 / C20`：CS

## 舵机

- `50 / C31`：PWM
- `52 / C30`：PWM

## 摄像头 CSI

- `36 / B20`：PCLK
- `38 / B22`：VSYNC
- `44 / B31`：D0
- `43 / B30`：D1
- `45 / B29`：D2
- `46 / B28`：D3
- `41 / B27`：D4
- `42 / B26`：D5
- `39 / B25`：D6
- `40 / B24`：D7
- `54 / C28`：摄像头配置 UART5_TX 或 I2C_SDA
- `51 / C29`：摄像头配置 UART5_RX 或 I2C_SCL

## FlexIO 第二路摄像头

- `75 / C5`：PCLK
- `76 / C6`：HREF
- `73 / C7`：VSYNC
- `74, 71, 72, 69, 70, 67, 68, 65`：`C8-C15`，图像数据 D0-D7
- `78 / C4`：保留，不建议接普通外设

## USB

- `21`：USB_OTG2_DP
- `22`：USB_OTG2_DN

## 智能车推荐分配

- 电机 PWM：`D12-D15`
- 两路编码器：`B18/B19`、`C2/C24`
- IMU：`C20-C23`
- 屏幕：`B0/B1/B3`
- 摄像头：`B20/B22/B24-B31`
- 无线串口：`D16/D17`
- 外设电源使能：`CR`
