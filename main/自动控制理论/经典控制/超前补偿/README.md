## 理论知识

一个减速直流电机驱动单关节。电流环已经闭合，位置环的小信号对象用下面的连续时间模型近似：

`G(s) = 10 / [s(1 + 0.2s)(1 + 0.05s)]`

采用单位负反馈，三个环节可作如下工程解释：

- `1/s`：角速度到关节角度的积分；
- `1/(1+0.2s)`：电机与机械负载的主要动态；
- `1/(1+0.05s)`：驱动器或内环的带宽限制。

未校正开环为 `L0(s)=G(s)`。先计算或仿真它的增益交越频率和相位裕度；本场景预期增益交越频率约为 `6 rad/s`，相位裕度约为 `23°`，具体数值以你的工具结果为准。

设计超前校正器：

`C(s) = Kc(1 + Ts) / (1 + alpha*Ts)`, with `0 < alpha < 1`

建议先把校正后的交越频率选在 `4.5--5.5 rad/s`，目标相位裕度设为 `50°--55°`，并预留约 `5°` 的设计余量。不要直接套用一组控制器参数；在“理论知识”中记录你选择 `Kc`、`T`、`alpha` 和目标交越频率的理由。

## 实践

### 仿真与记录要求

1. 在同一张 Bode 图中比较 `L0(s)` 和 `L(s)=C(s)G(s)`，标出增益交越频率、相位裕度和增益裕度。
2. 仿真闭环 `T_yr(s) = C(s)G(s) / [1 + C(s)G(s)]` 对 `0.1 rad` 位置阶跃的响应，记录上升时间、超调量、调节时间和稳态误差。
3. 同时观察控制器输出 `U(s)/R(s) = C(s) / [1 + C(s)G(s)]`，检查阶跃后的快速振铃、尖峰和高频纹波，避免只看关节位置曲线。
4. 保存校正前后 Bode 图、阶跃响应图、控制器输出图以及原始参数或脚本，使结果可以复现。

### 验收判据

| 指标 | 要求 |
|---|---:|
| 相位裕度提升 | 至少 `20°` |
| 校正后相位裕度 | 建议不低于 `45°` |
| 阶跃响应 | 无持续振荡或明显快速纹波 |
| 高频振铃 | 首次峰值后的快速纹波峰峰值小于阶跃幅值的 `1%` |
| 控制器输出 | 无持续高频振荡，并记录校正前后峰值 |
